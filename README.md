# Superstore-Sales-Dashboard
1.Superstore Sales Dashboard | Power BI

2.Project Overview
This project is an interactive Power BI Sales Dashboard created using the Sample Superstore dataset. The dashboard provides valuable insights into sales performance, profit, customer segments, product categories, and regional trends. It helps users analyze business performance and make data-driven decisions through interactive visualizations.

3.Objectives
Analyze overall sales and profit performance.
Compare sales across different regions and states.
Identify top-performing products and categories.
Evaluate customer segments and purchasing patterns.
Monitor business KPIs using interactive dashboards.

4.Dataset Information
The dataset contains retail order information, including:
Order Date
Ship Date
Customer Name
Segment
Region
State
Category
Sub-Category
Product Name
Sales
Quantity
Discount
Profit

5.Tools & Technologies
Power BI Desktop
Power Query (Data Cleaning & Transformation)
DAX (Measures & Calculations)
Microsoft Excel (Dataset)

6.Dashboard Features
 Total Sales, Profit, Quantity, and Orders KPIs
 Sales Trend Analysis
 Regional Sales & Profit Analysis
 Category & Sub-Category Performance
 Customer Segment Analysis
 Interactive Slicers and Filters
 Dynamic Visualizations
 
7. Key Insights
Identified the most profitable product categories.
Compared sales performance across different regions.
Analyzed the impact of discounts on profit.
Tracked sales trends over time.
Evaluated customer purchasing behavior by segment.
